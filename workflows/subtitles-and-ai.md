# 字幕与 AI

- 中文使用「」、作品名使用《》，中英文/数字间留空格，中文逗号全角。英语撇号使用 ’，引文使用 ‘ ’ / “ ”；代码、网址、路径、数学表达式和有效 JSON 保持原样。
- Whisper 解码提示只放媒体词汇，不注入长篇聊天格式要求。排版在转写后处理及语言模型提示中执行。
- 保存模型可用 token 时间戳，合并 BPE 词片并校验文本与时间，再通过动态规划综合完整词序列的标点、停顿、长度选择断句点，保护数字 / 单位、所有格与功能词搭配，优先新分句起点。长度是软约束，不能为凑固定时长拆开 `4,000 acres`；真实长停顿和说话人边界优先，不按字符比例伪造词对齐。
- 固定 Whisper CLI b5454 的 VAD 输出可能把句子放在原音频时间轴、token 留在压缩时间轴。`WhisperTimeline` 只使用引擎日志完整的 `vad_segment_info` 实测映射恢复词时间，并按整块校验选择时间轴，防止重复映射。缺失 / 不完整映射或无效词时间继续保留原句边界。Whisper / ONNX 断句检查点版本已递增；旧字幕和既有提案不会被静默重新切分，重新转写才能使用新缓存策略。
- ASR 将撇号和缩写后缀拆为带空格词片时，在断句前合并已知英语后缀并保留原始时间跨度；重建句子后再执行排版。保留引文和换行边界，不能全局删除撇号两侧所有空格。
- 「优化英语断句」中的本地 AI 标点恢复默认勾选，按含相邻上下文的批次处理；只允许标点和大小写调整，验证单词、数字及顺序不变。常规 ASR 自动断句不额外启动语言模型。无可靠词时间戳时保留整段时间；已有译文不能随意重分而错位。
- 翻译默认全文，明确范围及目标语言；进度写入持久提案，原字幕在允许前不变。完成或停止后可在中间字幕区查看差异 / 修改前 / 修改后，允许 / 拒绝 / 稍后；已完成的部分译文也可从版本历史找回。允许后提供首条译文入口。API 提供方显式配置，发送前确认地址和范围，密钥仅在凭据管理器保存。
- 翻译使用冻结的完整原文快照，将相邻目标字幕分为最多 8 条、约 3000 字符的小批，批次前后各补最多 2 条原文（每侧最多 1200 字符）。联合理解续句、数字单位、代词和术语，返回固定编号的 JSON 后，逐条校验编号齐全 / 唯一 / 非空，只把选中目标译文保存到提案；上下文译文丢弃，原文、词时间和未选中条目不变。取消保留已保存目标，格式错误整批拒绝，不把解释或编号错位当作译文。模型需支持结构化翻译。
- 上下文来自原文，不使用旧译文或前一批生成结果。选择未翻译 / 选中范围时仍可读取范围外邻居，API 确认明确披露会发送这些相邻原文；不发送已有译文或音视频。Index 专用翻译模型在单句加上下文时仍会漏掉续句单位，故使用联合 JSON 翻译；实测与模拟接口验证分开记录。
- 新生成的每条译文省略末尾句号（中文 / 英文，包含闭合引号前的句号），保留句内标点、问号、感叹号、省略号及 URL / 路径。提示和返回结果统一约束，本地模型与 API 使用同一规则；不批量改写已有译文或原字幕。
- 英语语气词清理、全文 Agent、版本历史、Diff 和回滚见 [字幕 Agent 与版本](transcript-agent.md)。
- 问答核对全部转写片段，长内容先逐段提取证据再合并，引用原始时间点；片段没提及不能推断全文没提及。历史回答可能有误，转写证据优先。
- SRT / VTT / TXT / ASS 区分双语、原文和译文；译文缺失时明确拒绝纯译文导出。JSON 保留完整项目，不能把它当成纯译文导出。
