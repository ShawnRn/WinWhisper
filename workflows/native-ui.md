# 原生界面

- 原生控件负责键盘、输入法、辅助功能和状态；共享 G2 几何负责绘制。控件模板在初帧确定轮廓，不在悬停后扫描并修改状态拥有的属性。
- 模板内 Grid / Border 的绘制子项通过 `InsetOwner` 订阅该命名部件的 Padding / BorderThickness，仅补偿自身绘制边距，覆盖外轮廓；不能漏掉 Padding 而把背景挤到正文区域。原生部件类型、内容布局、状态画刷与 Clip 保留。Expander 共用左侧拉伸、20 px 正文留白、圆角与字体，首次引导把技术详情收进默认折叠的高级选项。
- SDK 模板由 `scripts/update-native-surfaces.ps1` 生成，保留命名部件的 CLR 类型及原生结构。例如 ComboBox 依赖 Border → ScrollViewer → ItemsPresenter，不能为了圆角插入额外布局层。
- 交互项只画一个选择/悬停表面，避免外层直角和嵌套灰底。小表面按显示缩放进行抗锯齿采样。
- 页面、返回、前进和视图切换尊重系统动画及应用减少动画设置；快速导航必须清理旧动画状态。
- 通知占独立布局行，长消息换行；不能覆盖顶栏。弹层提供关闭入口、外部点击收起及原生展开/收起动画。
- 播放控制在画面外；宽、中、窄窗口分别安排视频、字幕、编辑器和 AI。缩略图卡片保持封面比例、两行标题高度和元数据基线一致。
- Enter 发送，Shift+Enter 换行，IME 组词 Enter 不误发；空格播放/暂停不抢文字输入。播放跟随的选择事件不能反向触发跳转。
- 聊天气泡一致，复制图标在悬停或键盘聚焦时显示。流式文本只在用户靠近底部时跟随，主动上滚保留阅读位置。
- 转写累计快照按字幕 ID 合并到现有对象，列表只增删移动变化的条目，不替换 ItemsSource、不清空重建。连续更新回归需保留已实现容器、选中项、滚动位置、播放器、聊天及背景；进度不能触发页面进入动画。
- 界面英文字母和标点优先使用 Segoe UI Variable Text，中文回退到随包的 Noto Sans SC，避免弯撇号采用全宽字形。
- 默认原生纯色背景，Mica 可选。静态截图和布局检查不能证明逐帧无闪烁，仍需真实窗口观察。
