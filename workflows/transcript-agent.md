# 字幕 Agent 与版本

- 右侧默认回答全文问题；开启「修改字幕」后，输入成为修改要求。完整字幕先冻结为基准快照，本地模型可调用 `read_transcript`、`search_transcript` 和 `propose_edits`。读取分页、搜索结果明确区分摘录与全文；最终编辑逐批覆盖全部字幕，不把搜索片段冒充全文。
- 工具循环最多 6 轮，搜索词与读取页有边界。只允许字幕能力，不开放 Shell、任意文件、网络或由模型直接应用修改。所有工具事件带运行 ID、序号、状态和时间；停止传播取消信号。参考 Proma 的 runtime / capability / event 组织方式，由 C# 独立实现，出处见 CREDITS。
- 模型补丁逐条校验 ID、数量和顺序，禁止自行生成时间。标点模式拒绝修改任何单词 / 数字；普通纠错改变词语后清除失效词对齐、保留原字幕时间。重分只使用真实词时间戳和音频停顿。
- 每份提案包含父版本、基准哈希、完整前后字幕、要求和工具记录，保存到本地 SQLite。生成中、待审阅、已应用、已拒绝、失败、停止分开记录；未完成的运行不冒充可应用提案。
- Diff 在中间原有字幕区显示，原位切换差异 / 修改前 / 修改后，播放器及右侧对话保持可见；不使用遮住工作区的审阅弹窗。列出修改、删除、新增及重新切分，底部选择「允许修改」「拒绝修改」或「稍后」。允许时同时校验内存和持久字幕基准及当前父版本，再在同一个事务内提交字幕与提案状态；重复决定不能重复写入或覆盖较新的版本。切换页面或关闭窗口等同稍后，提案保留。
- 差异按英语词 / 中文及 emoji 字素比较，公共文字保持正常颜色，仅删除片段标红并划线，新增片段标绿。逐字保留前后文本，不把整条已修改字幕全部染色；大输入保留公共前后缀并限制比较矩阵内存。
- 仅新增 / 修改译文时，未变化的原文只显示一次作为上下文；下方只对比译文，不把原文重复为减号 / 加号两行。时间或说话人变更同样不重复未修改正文。
- 字幕页右侧的历史按钮可跨重启找回待审阅提案、查看运行记录和恢复旧版本。过期提案只允许拒绝 / 稍后；重新生成后才可应用。回滚本身创建新提案 / 新版本，不删除后续历史；Ctrl+Z 仍可快速撤销。
- 手工保存记录字幕检查点，转写进度批次不反复建版本；任务完成后建立最终检查点。移除媒体一并清除对应版本，外部原始音视频保持不变。此机制只管理字幕，不管理源音视频的版本。
- 自动语气词清理仅处理独立 uh / um 及其拉长形式，默认用于新转写，可在全局或媒体参数关闭。已有字幕通过菜单生成清理提案；原文改变后提示失效译文。like、well 等实义词不默认删除。
- 验证：核心覆盖完整批次、停止不写入、非法工具拒绝、ID / 词序 / 时间校验、重启恢复、允许 / 拒绝、基准冲突和追加式回滚。原生回归验证模式、完整 Diff / 前后视图、应用撤销和过期预览；真实本地模型另行验证，不能用模拟响应代表模型质量。
