# 验证

1. 核心改动运行 `scripts/test.ps1`；转写、时间戳和媒体导出运行 `scripts/test.ps1 -Integration`。所有输出进入忽略的 `artifacts/`。
   - VAD 时间轴回归包含真实前导 30 秒静音的音频；可加 `-WhisperCache <chunk 文件前缀>` 只读检查已有 JSON / 引擎日志，结果只写测试目录，不能用生成的旧字幕检查点冒充新推理。
   - `-Ollama` 同时实测 Index-Translate-9B 的相邻数字 / 单位和代词上下文。结构化编号、范围外邻居、冻结原文、API 发送内容、逐条进度与取消使用独立夹具验证；真实云 API 未调用时必须注明。
2. 原生 UI 运行 `scripts/test-ui.ps1 -Rid <RID>`，使用隔离的 `--data-root`。修改视频或窗口生命周期时加 `-PlaybackVideo <path>`，检查视频加载后进程退出码为 0。
3. 两种架构分别构建和运行。ARM64 机器执行 x64 时明确记录为兼容执行，不能冒充物理 x64 验收。
4. 检查真实原生窗口：初次加载、悬停/离开、禁用/选中、三个窗口宽度、主题、滚动、快速导航、IME 和真实按键。
5. Computer Use 使用 `@oai/sky`，一次观察后执行一次输入并刷新；被用户输入打断就重新观察，不能沿用旧索引或坐标。只操作授权应用，测试不清理个人数据。
6. 遇到布局失败，区分真正的绘制问题、离屏元素、未完成布局和已被重新生成替换的旧容器；检查当前可见控件，不能放宽断言掩盖问题。
7. 记录测试命令、报告路径、真实后端、设备、取消和恢复结果。模拟服务验证与真实模型/远端服务验证分别说明。
8. ONNX GPU 测试按实际 Provider 算子记录确认，缓存结果不能冒充新 GPU 执行。已知失败的模型 / 后端组合见 `docs/GPU.md`；其他量化和语言不可沿用别的版本的内容验收结论。
9. 安装程序还需运行 `scripts/test-installer.ps1`，验证当前用户及所有用户范围、Universal 架构选择、独立 x64 Worker、默认无桌面快捷方式、包内 CLI 启动、升级、安装后 UI 与卸载。所有用户验证在已有管理员权限的 CI 执行，不通过自动化批准 UAC。
