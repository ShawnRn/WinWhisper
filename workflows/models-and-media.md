# 模型与媒体

- 模型商店按转写、翻译与对话、配音、语音辅助分类。模型下载在商店与首次引导中提供，设置用于参数、服务与路径配置，并可重新进入首次设置。
- 每个模型声明引擎、语言、大小、许可和硬件约束；下载后校验并原子安装，再应用。ONNX 使用 `.asr.json` 清单，不猜测任意 ONNX 文件的模型结构。
- CUDA、Vulkan、DirectML 等后端需要匹配架构的运行时及真实推理证据。不能因为选择 GPU 或存在显卡就标记为 GPU 执行；算子回退和兼容进程要明确说明。
- ONNX 自动尝试 CUDA → DirectML → CPU。CUDA 可选组件只在商店下载；ARM64 的 CUDA 使用 x64 兼容 Worker。先完成受限 GPU 探测，再执行正式任务；有效执行事件和正常原生退出共同决定是否成功。具体模型限制见 [GPU 支持](../docs/GPU.md)。
- 模型下载显示进度并可取消；CPU 为兼容回退。GPU 密集型任务默认串行，原生崩溃由 Worker 隔离。
- 录音支持系统、麦克风、混合和单 App 进程树；边录边转将已完成 PCM 片段发给工作进程。先保住音频，再处理剩余转写；失败不能丢录音。
- 在线下载、Cookie 读取和第三方导出必须用户触发，禁止记录凭据和 Cookie 值。
- 删除前说明自有录音、缓存、字幕、聊天和任务历史的清理范围；保留外部媒体及共享引用，拒绝越界、重解析点和仍有写入的会话。
