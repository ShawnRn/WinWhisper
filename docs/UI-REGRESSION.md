# 模型切换闪烁修复

模型商店应用模型曾调用全局设置刷新，重复创建 MicaBackdrop；随后清空并重建整个模型列表。这会重置背景合成和控件布局，造成整窗闪烁和滚动、焦点不稳定。

现在应用模型只保存模型配置，并更新现有卡片、按钮和状态文字；只有真正改变外观时才更新主题或背景。同一模型重复点击直接返回。按钮预留固定最小宽度，避免勾选文字出现时推动布局。模型下载进度也更新现有控件，并限制更新频率。

真实 WinUI 窗口回归验证使用独立 SQLite 数据目录和测试模型名称，不联网、不启动推理，不修改日常模型选择。执行：

```powershell
./scripts/test-ui.ps1 -Rid win-arm64
./scripts/test-ui.ps1 -Rid win-x64
```

每次连续切换翻译、总结模型共 24 次，断言 Mica、窗口子树、模型卡片和按钮引用不变，滚动偏移和按钮焦点保持稳定，并重新读取 SQLite 确认两种模型均已保存。报告保存到 `artifacts/ui-tests/<RID>/`。这验证了引发闪烁的背景和控件重建路径已移除；不把静态截图当成逐帧无闪烁测量。
