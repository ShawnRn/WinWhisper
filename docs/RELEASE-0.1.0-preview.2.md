# WinWhisper 0.1.0 Preview 2

本次预发布集中更新首次使用、字幕编辑与翻译体验。

- 首次启动引导检测电脑资源，推荐合适的模型，资源充足优先 Whisper large-v3；一键校验下载，支持暂停、继续和返回上一步。
- 自有后台进程统一为 WinWhisper.Worker；当前媒体可新建独立对话、搜索和恢复历史及草稿。
- 完整字幕 Agent 支持全文读取、搜索、纠错、去 uh / um、标点与断句建议。提案在中间字幕区原位显示，仅变化词标色，允许 / 拒绝 / 稍后及持久版本回滚均保留。
- 修复 Whisper VAD 时间轴，结合可靠词时间与停顿优化英语断句；相邻字幕联合翻译，参考冻结上下文，新增译文省略最终句号。仅翻译时不重复显示原文。
- 修复转写进度导致的全界面重建，统一英语弯引号与紧凑撇号、模型商店分类、通知、展开区域、媒体卡片、字体和聊天气泡。
- 完善 Enter 发送、空格播放 / 暂停、时间引用播放与字幕选择跟随。

提供 Universal、x64、ARM64 标准 Windows 安装程序。默认当前用户安装，可选所有用户安装；桌面快捷方式默认不勾选，升级和卸载保留用户数据。

安装程序未签名。模型权重按需下载，不随安装包提供；本地 AI 需要自行准备模型或 Ollama。GPU 后端依赖模型、驱动与算子，已知组合限制见 [GPU 支持](GPU.md)。模型容量推荐不是实测 GPU 吞吐保证；词时间和自动翻译仍需人工核对。

验收细节、实际构建提交、安装包哈希与托管安装测试结果随发布资产 `RELEASE-QA.json` 提供。ARM64 本机和 x64 兼容执行、托管 x64 安装检查分别记录，不将无桌面的托管检查描述为 GUI 验收。
